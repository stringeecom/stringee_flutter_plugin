# stringee_flutter_plugin_example

Demonstrates how to use the stringee_flutter_plugin plugin.

## Getting Started

Install Android SDK Platform 36, then run the example from this directory:

```shell
flutter pub get
flutter run
```

The example uses the plugin from the parent directory through a path dependency. Before publishing
or testing a release build, run:

```shell
flutter test
flutter build apk --release
```

For general Flutter setup help, see the official
[Flutter documentation](https://docs.flutter.dev/get-started/install).
